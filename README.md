# Skydive Pharaohs — Flight to memory

Interactive bilingual design preview by Traffic Digital Solutions.

Bookings and payments are simulated. Nothing is charged or reserved. This is a proposed customer experience, not the operational booking platform.

Open `index.html` locally or visit the GitHub Pages deployment. Arabic/English switching and the full customer journey are included.

The site is static: HTML, CSS and JavaScript are packaged in `index.html`, with relative image paths under `assets/`. No build or server credentials are required. Publish the `main` branch root through GitHub Pages.

Client imagery and brand identity remain their respective owner's property. Feather icons use the included MIT license. Tender documents, customer records and private service credentials are not part of this repository.
